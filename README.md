# ParkShare - Peer-to-Peer Parking Marketplace

This is a premium, responsive web application for finding and listing parking spaces.

## Features
- **Hero Section**: Premium design with glassmorphism effects.
- **Find a Spot**: Dynamic grid of available parking spots with search and filtering.
- **Rent my Spot**: Sleek form for listing your own parking space.
- **Fully Responsive**: Works on Desktop, Tablet, and Mobile.

## How to Run Locally

Since this uses modern Vanilla JS and CSS, you can run it using any simple web server. A quick way is using Python, which is already installed on your system.

1. Open your terminal in this directory.
2. Run the following command:
   ```bash
   python -m http.server 8000
   ```
3. Open your browser and navigate to:
   [http://localhost:8000](http://localhost:8000)

## Technology Stack
- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system (Dark Mode).
- **Vanilla JS**: State management and UI logic.
- **Lucide Icons**: Modern, scalable iconography.
